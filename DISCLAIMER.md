# Responsible use

Feature Heist exists to understand and reimplement behaviour **you are allowed to study**: open-source software, public APIs, contracts deployed on public chains, or software you own or are licensed to analyse for interoperability. That's the same position as [REA's disclaimer](https://github.com/morluto/rea/blob/main/DISCLAIMER.md).

- Don't use it to get around licensing, DRM or access controls, or to copy proprietary code.
- Rebuilds here are clean TypeScript reimplementations of *behaviour*. Original code appears only as clearly licensed test oracles (see `THIRD_PARTY_NOTICES.md`).
- Redact personal data from captures before analysing or committing them (`scripts/redact-har.mjs`).
